# Agent Workspace Protocol

AWP helps a coding agent set up a project workspace with local instructions and documentation.

1. Download [bootstrap/AGENTS.md](bootstrap/AGENTS.md) and save it as `AGENTS.md` in your new project folder.
2. Open that folder in your coding agent. Ask it to read `AGENTS.md` and describe what you want to build.

The agent sets up the workspace and replaces the starter file with your project instructions. Future sessions use the local files.
