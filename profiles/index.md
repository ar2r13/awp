# Module profiles

Choose profiles from the user's needs, not from a fixed workspace skeleton.
Read only those that apply. These are bootstrap guidance; integrate the applicable
parts into local module instructions rather than linking here at runtime.

| Need | Profile |
| --- | --- |
| Browser or other user-facing client | [client.md](client.md) |
| API, backend, worker, or service | [service.md](service.md) |
| Reusable package or library | [library.md](library.md) |

Other module types can use the generic module template. Apply stack defaults only
where a profile explicitly defines a fallback. Use supplied standards and record
their source; do not assume access to previous projects or installed skills.
