# Working in this workspace

Use the root and target module instructions. Follow links from the
[documentation map](../index.md) when they answer a question for the current task.

- Use the user's current request and confirmed project decisions. Read vision for
  product scope, architecture for module boundaries, and brief for original intent
  when those questions matter to the task.
- Inspect existing work, follow its style, and keep the diff focused.
- Keep unknowns explicit. Ask only when an answer is needed to proceed; use
  reasonable reversible choices within the authorized scope.
- Run relevant available checks. Report what was checked and what remains untested.
- Update the document that owns a changed fact. Do not copy the same fact into
  several summaries or append a session diary.
- Read [memory.md](memory.md) before saving durable context or a handoff.
- Read [delegation.md](delegation.md) before delegating substantial independent
  research, context sorting, or implementation. Keep simple tasks in one agent.
- Read [collaboration.md](collaboration.md) when another agent's work overlaps or
  when coordinating concurrent tasks. No mandatory multi-agent ceremony for solo work.
- Protocol source links are provenance. Do not fetch updates during ordinary work.
